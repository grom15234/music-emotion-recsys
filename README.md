\# Адаптивная система музыкальных рекомендаций на основе эмоционально-речевых маркеров



Проект в рамках ВКР. Система анализирует речь пользователя, извлекает эмоционально-речевые маркеры, определяет эмоциональное состояние и адаптивно подбирает музыкальный контент.



\## Изменения

\- Добавлено описание проекта

\- Зафиксирована цель: адаптивный подбор музыки по эмоциям
